# Portfolio

- Use Bun for all package management, scripts, builds, and TypeScript checks.
- Run `bun check`, `bun run lint`, and `bun run build` before committing.
- Use Conventional Commits. Keep content and commit messages in English.
- Keep the site dark, accessible, responsive, and free of inflated marketing copy.
- Do not invent employment details, metrics, project capabilities, or English proficiency.
- Keep resume content in `src/content.ts`; both PDF languages use that source.
- Deploy static output only. Follow `docs/deployment.md`; never restart unrelated services.
- Never commit credentials, machine-local files, original resumes, or private project source.
